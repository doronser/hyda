# HyDA: A Hypernetwork Framework for Unsupervised Domain Adaptation for Medical Images

This repository contains the official implementation of the MICCAI 2025 paper: "HyDA: A Hypernetwork Framework for Unsupervised Domain Adaptation for Medical Images".

## General Architecture

HyDA is a hypernetwork-based framework designed to perform unsupervised domain adaptation for medical images. The framework consists of two main components:

1. **Main Network**: Performs the actual task (e.g., classification, regression) using the weights generated by the hypernetwork.
1. **Domain Network**: Learns domain-specific features to help the hypernetwork generate task-specific weights.
1. **Hypernetwork**: Generates weights for the main network based on implicit domain features.

The architecture is designed to handle different medical imaging tasks, including brain MRI age prediction and chest X-ray pathology classification.

## Implementation Overview
The implementation is written using Pytorch Lightning to enable modular design and YAML configs with CLI overrides.
The core modules are written in pure python, which are wrapped in Pytorch Lightning modules for training logic.
Directory structure is as follows:
```
HyDA/
├── brain_mri/
│   ├── configs/
│   ├── data/
│   ├── models/
│   ├── pl_modules/
│   └── ...
├── chest_xray/
│   ├── configs/
│   ├── data/
│   ├── models/
│   ├── pl_modules/
│   └── ...
├── hyda/
│   ├── layers/
│   ├── utils/
│   └── ...
└── ...
```

* `configs/`: Contains YAML configuration files for experiments. 
* `data/`: Contains data loading and preprocessing scripts.
* `models/`: Contains `nn.Module` implementations.
* `pl_modules/`: Contains `LightningModules` implementations.
* `utils/`: Contains utility functions and scripts.
* `hyda/`: Contains shared layers and utilities.


## Experiment Types

### 1. Brain MRI Age Prediction

This experiment aims to predict the age of a patient based on brain MRI scans. The dataset used for this experiment was obtained using a combination of publicly available datasets and some proprietary data.

#### Usage
To train a baseline model:
```bash
python train.py fit -c brain_mri/configs/baseline.yaml --data.target_domain ixi brain_age_baseline
```

To train HyDa model:
```bash
python train.py fit -c brain_mri/configs/hyper.yaml --model.init_args.target_domain ixi--data.target_domain ixi brain_age_hyda
```

### 2. Chest X-ray Pathology Classification

This experiment aims to classify pathologies in chest X-ray images. The datasets used in this experiment are the
[NIH](https://www.nih.gov/news-events/news-releases/nih-clinical-center-provides-one-largest-publicly-available-chest-x-ray-datasets-scientific-community),
[VinBD](https://vindr.ai/datasets/cxr) and 
[CheXpert](https://stanfordmlgroup.github.io/competitions/chexpert/) datasets.

#### Example Usage

```bash
python train.py fit -c brain_mri/configs/baseline.yaml --data.target_domain 'ixi' brain_age_baseline

```
